# 3.3.9

> 发行日期：2026-11-18 · Windows x64 · 版本号 `3.3.9` / 文件版本 `3.3.9.0`

## 亮点

### 1. ADB 与 Fastboot 工具链改为内嵌，断网可用

- ADB、Fastboot 与两个 Windows 运行库随程序携带，启动时直接释放到独立运行目录，**不再依赖首次使用时联网下载**。
- 启动进度条按文件逐个显示释放进度，能看清当前在准备哪个工具。
- 已存在的工具文件经摘要校验一致后直接复用，跳过写盘，第二次启动明显更快。
- 程序退出不删除缓存；需要彻底清理时手动删除运行目录即可。

### 2. 资源包与模块状态判定更可靠

- 资源包改走云端资源键，后台未配置时回退内置直链，避免新旧地址混用。
- 模块安装状态改为按包文件时间戳判定，旧包残留不再被误报为安装成功。

### 3. 界面与操作

- 分区表、任务条与执行日志的布局保持稳定，读取 / 写入 / 擦除的进度与速率继续在同一条任务条上显示。
- 日志卡标题行保留连接模式显示（系统 / Fastboot / EDL / BROM / 未检测到）。

## 升级说明

- 从 3.3.x 升级可直接覆盖旧版本程序文件。
- 首次启动会释放内嵌工具链，运行目录出现约 20 MB 缓存属正常现象；之后启动复用缓存，不再重复写盘。

## 兼容性

- Windows 10 / 11（x64）。静态链接单文件，无需安装运行库。
- 系统模式需要手机开启 USB 调试并完成授权；Fastboot / EDL 模式需要对应驱动。
- 首次运行可能触发 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

## 已知问题

- 冷启动瞬间状态栏可能短暂显示"未检测到设备"，约 1～2 秒后给出最终状态；开发线（3.4.x）已针对该场景重做状态判定，见 [设计说明](../design-notes.md)。
- USB 链路速率徽标属于 3.4 开发线功能，未包含在本发行版中。
