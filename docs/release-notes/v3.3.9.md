# 3.3.9

> 发行日期：2026-11-18 · Windows x64 · 版本号 `3.3.9` / 文件版本 `3.3.9.0`

## 亮点

### 1. ADB 与 Fastboot 随程序提供，断网可用

- 客户端启动时把 ADB、Fastboot 与相关 Windows 运行库从内嵌资源释放到独立运行目录，进度条按文件逐个推进。
- 不再依赖首次使用时联网下载工具链：**没网也能进入命令环境**。
- 已存在的工具文件在校验通过后直接复用，跳过写盘，第二次启动明显更快。
- 程序退出不删除缓存；需要彻底清理时手动删除运行目录即可。

### 2. 设备状态与 USB 链路徽标

- 日志卡标题行新增 **USB 链路速率徽标**（USB 10G / USB3.2 / USB2.0 / USB1.1），大分区刷写前先确认链路。
- 设备状态文字与徽标共用同一次总线扫描，不额外占用线程。
- 宽度不足时按三档退化（完整文本 → 紧凑文本 → 隐藏徽标），保证与「保存日志」按钮永不重叠。

### 3. 用一条任务条讲清进度

- 当前操作、实时速率、单项进度、总体进度并列显示，任意时刻都能回答"现在在做什么、还要多久"。
- 停止按钮在当前步骤边界中断，界面状态与日志同步更新。

## 升级说明

- 从 3.3.x 升级可直接覆盖旧版本程序文件。
- 首次启动会释放工具链，运行目录出现约 20 MB 缓存属正常现象；之后启动复用缓存，不再重复写盘。

## 兼容性

- Windows 10 / 11（x64）。静态链接单文件，无需安装运行库。
- 系统模式需要手机开启 USB 调试并完成授权；Fastboot / EDL 模式需要对应驱动。
- 首次运行可能触发 SmartScreen 提示，选择「更多信息 → 仍要运行」即可。

## 已知问题

- 冷启动瞬间会显示"正在检测设备"，属正常识别过程，约 1～2 秒后给出最终状态。
- USB1.1 链路下大分区写入耗时较长，建议更换线材或接口。
