# 使用指南

本文按操作顺序说明 KMF 的界面分区、菜单入口与常见操作。程序版本以 [Releases](https://github.com/zts10086/kmf-toolkit/releases) 为准。

---

## 1. 界面分区

主界面分为四块，所有状态与结果都在这四块里出现：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 菜单栏 | 顶部 | 功能 / 通用功能 / 高通功能 / 其他功能 / 辅助功能 |
| 分区表 | 左中 | 列出 LUN、分区名称、大小、操作类型、文件路径 |
| 任务条 | 左下 | 当前操作、实时速率、单项与总体进度、停止按钮 |
| 执行日志 | 右侧 | 带时间戳的过程记录，右上角为设备状态、USB 徽标与「保存日志」 |
| 状态栏 | 底部 | 设备代号、BL 状态、当前槽位、用户分区、服务连接状态 |

标题栏旁的副标题显示当前会话属性（例如从官网或测试通道进入时的标识）。

---

## 2. 设备状态怎么看

日志卡标题行的设备状态文字是判断依据，取值含义如下：

| 显示 | 含义 | 建议动作 |
| --- | --- | --- |
| `系统模式` | 已进入 Android 系统，ADB 可用 | 可直接读分区表、开命令环境、投屏 |
| `Fastboot...` | 处于 Fastboot / Bootloader | 可执行分区写入、槽位切换等操作 |
| `EDL / 9008` | 处于高通下载模式 | 可执行下载模式相关操作 |
| `MTK BROM` | 联发科 BROM 会话 | 可执行 MTK 相关操作 |
| `设备：ADB离线` | 物理在线，ADB 通道未恢复 | 等待自动恢复，或重新插拔确认授权 |
| `设备：已连接` | 检测到设备但模式尚未确定 | 稍候会自动更新为具体模式 |
| `未检测到设备` | 三种协议均无响应 | 检查线材、接口、驱动与 USB 调试授权 |

**USB 链路徽标**与状态并列显示：

| 徽标 | 含义 |
| --- | --- |
| `USB 10G` / `USB3.2` | SuperSpeed 链路，大分区写入最快 |
| `USB2.0` | 高速链路，写入速度受限于 2.0 |
| `USB1.1` | 全速链路，通常意味着线材或接口有问题 |

徽标只做显示，不会改变任何操作结果；它出现 2.0 / 1.1 时优先换线或换口。

---

## 3. 读分区表

1. 连接设备，确认日志卡显示具体模式。
2. 点任务条的 **读分区表**。
3. 分区表按 LUN / 名称 / 大小 / 操作 / 文件路径列出，可输入关键字筛选，也可用「全选」与逐行勾选。

> 读分区表是只读操作，不会改动设备。切换模式后建议重新读取，不同模式能访问的分区范围不同。

---

## 4. 读 / 写 / 擦除分区

| 操作 | 前置 | 结果 |
| --- | --- | --- |
| 读分区 | 已读到分区表 | 把选定分区导出到本地文件 |
| 写分区 | 已选镜像、分区容量足够 | 把本地镜像写入选中分区 |
| 擦除分区 | 已读到分区表 | 清空选中分区内容 |

执行时任务条会显示「当前操作」、实时速率、单项进度与总体进度；需要中断时点 **停止操作**。写入前请核对三件事：

1. **机型**与镜像来源机型一致；
2. **分区名**与镜像用途一致（例如不要把 `boot` 镜像写进 `super`）；
3. **容量**：镜像体积不得大于目标分区。

「一键格机救砖」属于复合操作，会连续执行多个分区动作，使用前请确认已有完整固件可回退。

---

## 5. 引导文件与认证文件

分区表下方的文件区用于指定本次操作使用的引导与认证文件：

| 字段 | 用途 |
| --- | --- |
| 引导文件 | 指定本次会话使用引导镜像 |
| 欧加认证 Dig / Sign | 指定认证文件对（Digest / Signature） |
| 云端引导 | 在「本地引导」与云端来源之间切换 |
| XML 文件 | 指定划分或操作描述文件 |
| 自动重启 | 操作结束后自动重启设备 |
| 保护分区 / 保数据 / 读取信息 | 操作选项，按需勾选 |

---

## 6. 辅助功能

从顶部菜单 **辅助功能** 进入：

| 入口 | 作用 |
| --- | --- |
| 设备管理器 | 打开 Windows 设备管理器，排查驱动与识别问题 |
| adb命令 | 打开 ADB / Fastboot 命令环境（工具链随程序提供） |
| 一键投屏 | 把手机画面投到 Windows 桌面 |
| rom查询 | 按机型查询可用 ROM |
| 资源下载 | 查看分类资源与配套文件 |

ROM 查询与资源下载依赖网络与服务的可用性；命令环境在断网状态下依旧可用。

---

## 7. 日志

- 每条日志带 `[时:分:秒]` 时间戳；状态变化、失败原因、链路变化都会写入。
- 点 **保存日志** 导出为文本，便于提交问题或自行回查。
- 提交问题时请一并给出：程序版本、手机型号、连接模式、日志文本。

---

## 8. 退出与缓存

程序退出时**不会**删除运行期释放的工具链缓存，因此下次启动可直接复用（校验一致时跳过写盘）。需要彻底清理时，关闭程序后手动删除缓存目录即可。
